# MultiChart-TradingView

MultiChart-TradingView is a Windows desktop terminal for TradingView: one window with up to 16 synchronized chart panes, multiple tabs, and up to eight isolated TradingView sign-ins.

This repository is the public download channel. The application source code is not published here.

## Download

Open the [latest release](https://github.com/XUtility/MultiChart-TradingView/releases/latest) and pick the package that fits your machine:

- `MultiChart-TradingView_<version>_x64-setup.exe` — per-user installer, no elevation prompt (recommended)
- `MultiChart-TradingView_<version>_x64_en-US.msi` — for managed machines
- `MultiChart-TradingView-<version>-Portable.zip` — unzip anywhere and run the executable

`SHA256SUMS.txt` lists the SHA-256 of every asset. The in-app updater refuses to download a package without a published checksum and re-hashes the file on disk before running it.
